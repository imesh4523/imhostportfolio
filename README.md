## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/imesh4523/imhostportfolio.git
   cd imhostportfolio
   ```

2. Start the local server:
   ```bash
   node server.js
   ```

3. Open in browser:
   - Main Site: [http://localhost:3000/profile](http://localhost:3000/profile) or [http://localhost:3000/](http://localhost:3000/)
   - Refund Policy: [http://localhost:3000/profile/refund](http://localhost:3000/profile/refund)
   - Privacy Policy: [http://localhost:3000/profile/privacy](http://localhost:3000/profile/privacy)
   - Terms Policy: [http://localhost:3000/profile/terms](http://localhost:3000/profile/terms)
   - Live API Ping Test: [http://localhost:3000/api/ping](http://localhost:3000/api/ping)
